## 🔬 Overview

Environmental stressors (heat, air pollution, drought, extreme weather, radiation, microgravity) interact, but most analysis treats them independently. The unknown is not just the stressor; it is what happens when stressors interact. 

**SYNERA** couples:
1. **AI Discovery Engine**: Generates interaction hypotheses (synergy, antagonism, nonlinear threshold effects).
2. **Scientific Validation**: Rigorous frequentist and resampling statistics to validate findings.
3. **Cybersecurity & Provenance**: Cryptographic ledger and data integrity pipelines ensuring computational provenance is tamper-evident.
4. **Actionable Decision Support**: Climate-resilience and space-biology insights translated into operational recommendations.

> *"AI generates hypotheses. Science validates them. Blockchain does not prove the science; it makes the computational provenance tamper-evident."*

---

## 🏛️ The 7-Layer Architecture

1. **Layer 01 - Data Ingestion & Harmonization**: NASA OSDR/GeneLab omics, Open-Meteo, NASA POWER.
2. **Layer 02 - AI Discovery Engine**: Feature interaction mining, continuous response surfaces, anomaly detection.
3. **Layer 03 - Scientific Validation**: FDR control (Benjamini-Hochberg), variance moderation, block-bootstrapping, cross-dataset replication.
4. **Layer 04 - Cybersecurity & Integrity**: SHA-256 data signing, data poisoning detection, pipeline integrity checks.
5. **Layer 05 - Cryptographic Provenance Ledger**: Ed25519 signed append-only cryptographic ledger tracking every artifact and computation.
6. **Layer 06 - Web Intelligence Platform**: High-density interactive dashboard, 3D interaction manifold visualizations, evidence graphs.
7. **Layer 07 - Action & Decision Support**: Risk assessment, climate resilience indices, reproducible findings.

## 🚀 Quickstart

### Prerequisites
- Python 3.11+
- Node.js 20+
- Git

### Setup
```bash
# Set up Python virtual environment, dependencies, and frontend
make setup

# Run health and environment checks
make check

# Start API server
make api

# Start Web dashboard
make web
```
